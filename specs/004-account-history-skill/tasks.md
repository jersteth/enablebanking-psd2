## Phase 3 – History Core, Python API, `history` Command
**Goal**: the non-interactive fetch of all accounts to the versioned JSON, through both the CLI and Python.
**Verify (user)**:
1. `psd2-demo history --days 30 --include balances,details --output exports/h.json` exits 0, and the file validates: `python -c "import json,jsonschema; jsonschema.validate(json.load(open('exports/h.json')), json.load(open('schemas/account-history.v1.json')))"`.
2. Rerun it: every account shows `cached: true` and `api_calls: 0`.
3. `psd2-demo sessions revoke --account <one>` followed by `history` gives exit 3, with that account `consent_required`.

- [ ] 3.1 `history.build_document`, per-account algorithm:
  - cache hit; read-only session resolution (local + `get_session`) → `consent_required`
  - PSU from `SessionRecord.bank`, else `/aspsps` memoized per bank
  - transactions + truncation warning; optional balances/details with per-part warnings
  - `api_calls` from `request_count`; cache put on success
  - 429 → stale fallback or `rate_limited`; other errors → `error{step,…}`; unexpected exception → `step="internal"` (redacted message)

  Test: `test_history.py` (every status, partial, isolation, cache hit/miss/expiry, `no_cache`, stale fallback, part failure, `raw` include, `api_calls`, PSU source, store file unchanged). Each produced document is validated against the schema.
- [ ] 3.2 `history.fetch_history` (config load, include and range resolution with `UsageError` → `ConfigError`, lazy client creation so a fully cached run makes no network calls, injectable env/client/today/now). Test: `test_history_api.py` (no stdout, `ConfigError` cases, fully cached run creates no client requests).
- [ ] 3.3 `commands.history` + CLI subparser (`--account` repeatable, range, `--include` with `none`, `--output` atomic 0600 + V12 notice, `--max-age`, `--no-cache`, `--verbose`; exit codes 0/1/2/3/130; stdout carries only JSON; `--output` leaves stdout empty; an output write failure → exit 1). Test: `test_cli_history.py` (an end-to-end mocked API with two accounts, one consent_required → exit 3 + schema-valid stdout; every exit code; stdout purity).
